# Running costs

Researched 2026-10-17. USD converted at ~58 PHP/USD (approximate).

## Fixed costs
| Item | Cost | Per month |
|---|---|---|
| Apple Developer Program (iOS app) | $99/yr (~5,750 PHP) | ~480 PHP |
| Google Play Console | $25 one time (~1,450 PHP) | one time |
| Domain for guest links (estimate) | ~700 PHP/yr | ~60 PHP |
| Expo/EAS builds | Free plan (15 iOS + 15 Android builds) | 0 |
| Guest web page hosting (Vercel/Netlify/Cloudflare free tier, inferred) | Free | 0 |
| Supabase Free | 500 MB DB, 1 GB storage, 50k users; pauses after 1 week of no activity | 0 |
| Supabase Pro (once there's real traffic) | $25/mo | ~1,450 PHP |

## Per-invitation cost
- Manual QR payment: ~0 PHP. PayMongo QR Ph later: 1.50 PHP.
- Storage/database per invitation: fractions of a centavo.

## Break-even at 100 PHP per invitation
- Launch (Supabase free): ~540 PHP/mo, so about 6 invitations a month.
- Growing (Supabase Pro + PayMongo): ~2,000 PHP/mo, so about 21 invitations a month.

Not included: taxes (BIR registration, percentage tax/VAT) and Eric's time approving receipts.

Sources: [Supabase pricing](https://supabase.com/pricing), [Expo pricing](https://expo.dev/pricing), [App store fees](https://www.choicely.com/blog/expo-go-to-app-store)
