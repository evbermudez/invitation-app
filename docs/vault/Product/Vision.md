# Vision

A SaaS app where a host creates an invitation for an event and shares it with guests, who can RSVP.

## Host inputs
- Event name
- Location
- Event type (birthday, wedding, baptism, etc.)
- Date and time
- More fields to be decided (see [[Open Questions]])

## Pricing
- Each invitation costs **100 pesos** (assumed MXN), paid by the host.
- Guests never pay.

## Platforms
- Mobile first. See [[Decisions/0001 Mobile first]].
